# AI Engineering Kit

> Build software with AI the same way experienced engineering teams build software together.

AI Engineering Kit is an open-source knowledge base, playbook, and standards library for AI-assisted software development.

Unlike collections of prompts or model-specific rules, this repository focuses on **engineering knowledge** that can be shared between humans and AI coding agents.

The goal is simple:

> Make AI think more like an experienced software engineer.

---

## Why this project exists

Modern AI tools are incredibly capable, yet they often struggle with engineering consistency.

Typical problems include:

- creating duplicate components instead of reusing existing ones;
- making unrelated changes while fixing a bug;
- ignoring project architecture;
- introducing inconsistent naming;
- breaking design systems;
- prioritizing implementation over understanding;
- producing code that works but is difficult to maintain.

These issues are rarely caused by a lack of coding ability.

They are usually caused by a lack of **shared engineering context**.

AI Engineering Kit provides that context.

---

## What this repository is

AI Engineering Kit is a collection of:

- Engineering principles
- Decision frameworks
- Architecture guides
- Technology playbooks
- Development checklists
- Code review standards
- Prompt templates
- AI agent integrations
- Real-world examples

The repository is designed to be useful for both software engineers and AI coding agents.

---

## What this repository is NOT

AI Engineering Kit is **not**:

- a prompt library;
- a replacement for official documentation;
- a framework;
- a coding standard for a single language;
- a collection of AI hacks;
- a replacement for engineering judgment.

Instead, it provides reusable engineering knowledge that helps both humans and AI make better technical decisions.

---

## Core philosophy

This project is based on one simple idea:

> AI should not replace engineering thinking. It should amplify it.

Rather than teaching AI how to generate code, this repository teaches AI how experienced engineers approach problems.

The emphasis is on:

- understanding before implementation;
- consistency over cleverness;
- maintainability over shortcuts;
- evidence over opinion;
- reusable knowledge over model-specific prompts.

---

## Who this repository is for

AI Engineering Kit is intended for:

- Software Engineers
- Senior Engineers
- Tech Leads
- Engineering Managers
- Solution Architects
- AI-assisted development teams
- Open-source maintainers

Whether you use Cursor, Claude Code, Codex, GitHub Copilot, Gemini CLI, Cline, or another AI coding assistant, the engineering principles remain the same.

---

## Design principles

Every document in this repository follows the same principles.

Knowledge should be:

- practical;
- verifiable;
- technology-agnostic whenever possible;
- supported by engineering reasoning;
- easy for both humans and AI to understand.

Documentation is written for engineers first.

AI agents consume the same documentation naturally instead of relying on prompt engineering.
