# Next.js Engineering Standards

## Purpose

This section defines the engineering standards, architectural principles, and best practices for developing applications with Next.js.

The objective is to establish a consistent approach to building scalable, performant, secure, and maintainable applications using the App Router architecture.

These standards should be followed by both human developers and AI coding assistants.

## Engineering Principles

Every Next.js feature should satisfy the following principles:

- Server-first architecture.
- Minimize client-side JavaScript.
- Prefer React Server Components.
- Fetch data as close to the server as possible.
- Keep client components small.
- Optimize Core Web Vitals.
- Build for accessibility.
- Build for scalability.
- Build for maintainability.
- Measure performance before optimizing.
