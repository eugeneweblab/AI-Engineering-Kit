# Development Workflows

## Purpose

This section provides step-by-step recipes for common engineering tasks. Each workflow
sequences the work end to end and points to the knowledge topics you need at each step.

Where [`../engineering/`](../engineering/) and [`../ai/`](../ai/) describe *how to
think*, workflows describe *what to do next* for a specific kind of task.

These workflows apply to both human developers and AI coding assistants.

---

## Scope

This documentation covers task-level workflows:

- Implementing designs and building UI
- Fixing and investigating bugs
- Creating and refactoring features
- Reviewing pull requests
- Adding backend endpoints
- Building for specific platforms (React, WordPress, Divi, Gutenberg)

## How to Use

1. Pick the workflow that matches your task.
2. Follow its steps in order; each one links to the relevant knowledge topic.
3. Gather context first, implement in scope, and verify before finishing.
4. Close out with the target topic's `98`/`99`/`100` checklists.
