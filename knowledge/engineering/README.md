# Engineering Principles & Practices

## Purpose

This section defines the cross-cutting engineering discipline that applies to every
technology in this knowledge base: how to make decisions, review code, debug problems,
and execute tasks well.

Technology topics (`react`, `nodejs`, `aws`, …) explain *what* to build with a given
tool. This section explains *how* to think while doing it.

These practices apply to both human developers and AI coding assistants.

- Decision frameworks and trade-off analysis
- Code review standards
- Debugging methodology
- Task execution workflow
- Context-first development

## Core Principles

- Optimize for the reader and the next engineer, not for cleverness.
- Make decisions explicit; record the trade-offs.
- Prefer evidence over opinion.
- Understand the context before changing it.
- Leave the codebase more consistent than you found it.
